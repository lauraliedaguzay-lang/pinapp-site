ACCOMPAGNEMENT

Vous remplissez. Claude vous décortique.

Le but : recevoir un brief net, une estimation, et un prompt prêt pour analyser un message client, vérifier un site livré, ou auditer une automatisation.

Remplir le formulaire Demande simple

1) Qu’est-ce qu’on doit vérifier ?

Choisis le type, et je te pose les bonnes questions.

2) Contexte (en 30 secondes)

3) Site livré — ce que j’ai besoin de voir

3) Automatisation — ce que j’ai besoin de voir

3) Message à analyser

4) Pièces & code à vérifier

Tu peux coller du code, ou coller les fichiers dans un message séparé. Ici, on prépare un brief propre pour Claude.

5) Résultat attendu

6) Estimation

On reste simple : une fourchette basée sur le type + la complexité que tu coches.

Envoyer par email

Note Rien n’est envoyé automatiquement. Tout reste sur ton téléphone tant que tu n’appuies pas sur “Envoyer par email”.

SORTIE

Estimation —

Brief structuré

Prompt Claude (copier-coller)

Ce que Claude doit te rendre (format simple)

  • 1) Ce que je fais maintenant : 5 actions max, dans l’ordre.
  • 2) Les risques : ce qui peut casser / engager / coûter.
  • 3) Ce que je demande au client : questions indispensables, sans jargon.
  • 4) Vérifs QA : mobile, perf, accessibilité, SEO, formulaires.
  • 5) Correctifs : si code fourni, patchs ciblés.
