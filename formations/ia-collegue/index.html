L'IA, mon nouveau collègue

3 h 30 · 550 € HT

Vous repartez avec une grille « où l'IA m'aide », 5 prompts adaptés à vos vrais cas, et un assistant prêt dans Claude ou ChatGPT.

Ce que vous repartez avec

  • Grille personnalisée utile / pas utile / à creuser
  • 5 prompts du Kit testés sur vos données (devis, avis, calendrier, prix, assistant)
  • Assistant métier (system prompt) déployé + doc d'usage
  • Plan IA quotidien & hebdo + limites éthiques + replay

Le déroulé

?
Bloc 1 — Démystification (30 min)

5 démos sur votre métier : e-mails, résumé doc, idées business, avis Google, post réseaux — vous cochez utile / non / peut-être après chaque.

⌗
Bloc 2 — Atelier prompts (1 h)

Vous activez le Kit Prompt Artisan en live (prompts 4, 5, 12, 34, 39), puis vous modifiez un prompt : précise + contexte + format.

🤖
Bloc 3 — Assistant métier (1 h 30)

Prompt 39 → 10 questions réelles → ajustements → Custom Instructions ou projet Claude. Jeu de rôle client / assistant pour valider les réponses.

◎
Bloc 4 — Plan IA perso (30 min)

3 usages quotidiens, 3 hebdo, outils gratuits vs payants, ce que l'IA ne fera pas pour vous.

Pour qui

  • Vous utilisez déjà ChatGPT mais au hasard
  • Vous voulez industrialiser e-mails, devis et idées sans perdre votre voix
  • Vous préférez une preuve live sur VOS documents plutôt qu'un tutoriel générique
« Témoignage client à paraître après validation. »

FAQ

Faut-il acheter le Kit Prompt Artisan avant ?

Non : la session inclut l'usage live du Kit ; si vous n'avez pas encore le fichier, on travaille sur une copie de travail fournie le jour J.

ChatGPT ou Claude ?

Les deux : on choisit celui que vous utilisez déjà ; les prompts sont adaptables.

Données confidentielles ?

Utilisez des extraits ou des chiffres fictiles si besoin ; la méthode reste la même.
