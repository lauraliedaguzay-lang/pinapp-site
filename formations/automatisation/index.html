La règle d'or : déclencheur → action → notification

Toute automatisation, sur n8n comme ailleurs, tient en 3 temps. 1) Un déclencheur (un formulaire rempli, un rendez-vous dans l'agenda, une heure précise). 2) Une ou plusieurs actions (générer un PDF, envoyer un SMS, écrire dans un Google Sheet). 3) Une notification pour garder l'œil (un mail récap). Si vous savez décrire ces 3 lignes, vous savez automatiser.

3 automatisations qui rapportent (le process exact)

1
Rappel SMS la veille du RDV

Déclencheur : l'agenda (Google Calendar) → n8n lit les RDV du lendemain → action : SMS via votre fournisseur (Brevo, Twilio…) → notification : récap du matin par mail. Résultat : moins de lapins, zéro relance à la main.

2
Demande d'avis Google à J+7

Déclencheur : prestation marquée « terminée » (formulaire ou Google Sheet) → attente 7 jours → action : mail/SMS avec votre lien d'avis Google → notification : suivi des envois. Résultat : plus d'avis, sans y penser.

3
Devis PDF depuis un formulaire

Déclencheur : un formulaire de demande rempli → action : génération d'un PDF (votre modèle + les données) + envoi au client → notification : copie pour vous + ligne ajoutée au suivi. Résultat : un devis part en minutes, pas en jours.

Dépannage — les blocages courants (avant de nous écrire)

Mon workflow ne se déclenche pas

Vérifiez qu'il est activé (l'interrupteur en haut à droite), pas seulement enregistré. Pour un déclencheur planifié, contrôlez le fuseau horaire. Pour un formulaire/webhook, faites un « Execute workflow » puis envoyez une vraie soumission pour tester.

Le SMS / l'e-mail ne part pas

9 fois sur 10 c'est la « Credential » : clé API expirée, expéditeur non vérifié, ou crédit épuisé chez le fournisseur. Ouvrez le nœud, retestez la connexion et lisez le message d'erreur rouge — il dit précisément quoi corriger.

Ça envoie en double

Ajoutez une condition « déjà traité ? » : une colonne « envoyé = oui » dans votre Google Sheet, vérifiée avant l'action, pour ne pas retraiter la même ligne.

J'ai peur de tout casser

Dupliquez le workflow avant de le modifier et travaillez sur des données de test. n8n garde l'historique des exécutions : vous revoyez exactement ce qui s'est passé, étape par étape.

Et le RGPD ?

Données de test tant que possible, clés API sur vos propres comptes, hébergement européen. Ne stockez que le nécessaire et prévoyez une durée de conservation.
