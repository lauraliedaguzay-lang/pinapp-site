Aperçu

3 prompts gratuits

Même structure que dans le PDF payant : objectif, cible, temps gagné, prompt copiable, astuce, exemple de sortie.

Email de relance client (poli, ferme) 
📝 RELANCE CLIENT — POLIE ET FERME
🎯 Objectif : relancer un devis ou une validation sans agresser.
👤 Pour qui : artisan, commerçant, libéral.
⏱ Temps gagné : ~20 min.

PROMPT :
Tu es un·e conseiller·ère commercial·e en France. Rédige un email de relance (120–180 mots) pour [NOM CLIENT], concernant [OBJET : devis / commande / RDV]. Ton professionnel, chaleureux, une seule question claire à la fin, pas de culpabilisation. Signataire : [PRÉNOM], [ENTREPRISE].

💡 ASTUCE : colle le dernier échange client dans le chat avant d’envoyer le prompt.
📊 EXEMPLE DE RÉSULTAT : sujet + 3 paragraphes courts + appel à action unique.
Post LinkedIn storytelling (structure claire) 
📝 POST LINKEDIN — HISTOIRE DE TERRAIN
🎯 Objectif : un post crédible qui montre le métier sans jargon.
👤 Pour qui : dirigeant·e TPE / artisan·e.
⏱ Temps gagné : ~25 min.

PROMPT :
Écris un post LinkedIn (900–1300 caractères) sur cette situation réelle : [CONTEXTE EN 5 LIGNES MAX]. Structure : accroche concrète → tension / erreur fréquente → ce que tu as changé → 3 apprentissages → question ouverte. Interdit : superlatifs creux, hashtags en masse.

💡 ASTUCE : une anecdote précise (outil, météo, délai) bat toujours un discours générique.
📊 EXEMPLE DE RÉSULTAT : 1 accroche + corps scannable + question.
Organiser la semaine en 5 minutes 
📝 SEMAINE EXPRESS — PRIORITÉS RÉALISTES
🎯 Objectif : plan clair lundi matin, charge réaliste.
👤 Pour qui : indépendant·e débordé·e.
⏱ Temps gagné : 1–2 h / semaine.

PROMPT :
Voici tout ce que j’ai en tête cette semaine (liste brute) : [COLLE TA LISTE]. Classe en 4 blocs : (1) cash immédiat (2) livraisons promises (3) admin légal/factures (4) marketing. Donne un planning sur 5 jours avec 3 tâches max/jour et ce que je dois déléguer ou supprimer.

💡 ASTUCE : indique tes horaires réels (ex. coupures 12h–14h).
📊 EXEMPLE DE RÉSULTAT : tableau jour par jour + « à supprimer ».
