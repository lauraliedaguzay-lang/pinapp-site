Prompt 2 · Email de relance client 
🎯 Objectif : Relancer un client sans être lourd
👤 Pour qui : Tous secteurs
⏱ Temps gagné : 20 min

PROMPT :
Rédige un email de relance pour un client qui n'a pas répondu à mon devis envoyé il y a [nombre] jours.

Mon métier : [votre métier]
Objet du devis : [ce que vous proposiez]
Montant : [prix]
Relation avec le client : [nouveau / déjà client / recommandé par...]

L'email doit :
- Être court (max 100 mots)
- Rappeler brièvement l'objet sans recopier le devis
- Montrer que vous comprenez qu'ils sont occupés
- Proposer une alternative (appel rapide, nouveau créneau)
- PAS de culpabilisation, PAS de pression
- Signer avec votre prénom uniquement
- Objet du mail inclus
Prompt 9 · Post LinkedIn storytelling 
🎯 Objectif : Écrire un post LinkedIn qui génère de l'engagement
👤 Pour qui : Tous secteurs
⏱ Temps gagné : 30 min

PROMPT :
Rédige un post LinkedIn basé sur cette situation vécue dans mon travail :

Mon métier : [votre métier]
La situation : [racontez brièvement ce qui s'est passé]
La leçon : [ce que vous en avez tiré]
Mon objectif avec ce post : [notoriété / clients / recrutement / partage]

Structure AIDA :
1. ACCROCHE : 1ère ligne qui arrête le scroll (max 10 mots, percutante)
2. HISTOIRE : racontez la situation en 5-6 lignes courtes (1 idée par ligne, retours à la ligne fréquents)
3. LEÇON : ce que ça vous a appris (2-3 lignes)
4. APPEL : question ouverte pour les commentaires

Règles :
- Lignes courtes (max 10 mots par ligne)
- PAS de hashtags dans le texte (les mettre à la fin, séparés)
- PAS d'emojis au début de chaque ligne
- Ton : authentique, pas motivational speaker
- 5-8 hashtags pertinents à la fin
- 150-200 mots max
Prompt 17 · Organiser sa semaine en 5 minutes 
🎯 Objectif : Planning hebdomadaire structuré
👤 Pour qui : Indépendants, artisans
⏱ Temps gagné : 30 min

PROMPT :
Aide-moi à organiser ma semaine.

Mon métier : [votre métier]
Mes créneaux de travail : [ex: lun-ven 8h-18h]
Mes rendez-vous déjà calés cette semaine : [listez-les]
Mes tâches urgentes : [listez-les]
Mes tâches importantes mais pas urgentes : [listez-les]
Mes tâches récurrentes : [ex: compta le vendredi, réseaux le lundi]

Crée un planning jour par jour avec :
- Les blocs de temps (matin / après-midi)
- Les tâches assignées à chaque bloc
- 1h de batterie/imprévu par jour
- La pause déjeuner (sacrée)

Format : tableau simple, lundi à vendredi.
Règle : max 3 tâches importantes par jour. Si j'en ai plus, reporte au jour suivant.

Comment utiliser ce kit

  1. Copiez le prompt tel quel dans ChatGPT ou Claude
  2. Remplacez les [crochets] par vos informations
  3. Relisez et personnalisez le résultat (l'IA donne une base, vous ajoutez votre touche)
  4. Testez différentes versions — relancez le même prompt 2-3 fois pour comparer
  5. Sauvegardez vos prompts préférés dans un dossier
