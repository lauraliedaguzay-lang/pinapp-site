Formations présentiel · Lauralie

Mon site qui travaille tout seul

3 h 30 · demi-journée · 550 € HT (TVA non applicable art. 293 B)

Vous repartez avec une page qui tourne, un message qui accroche, et la preuve que vous pouvez la modifier seul.

Ce que vous repartez avec

  • Fiche diagnostic PDF remplie sur votre site (ou benchmark concurrent)
  • Pitch en 3 versions (formel, décontracté, express) + test IA en live
  • Page d'accueil fonctionnelle ou maquette personnalisée + test CTA
  • Enregistrement vidéo de la session + doc récap

Le déroulé

◎
Bloc 1 — Diagnostic live (45 min)

Audit express (charge, CTA, mobile, clarté, contact). Comparaison avec une démo Pinapp de votre secteur. Livrable : fiche diagnostic PDF.

✎
Bloc 2 — Atelier « Mon message » (45 min)

Exercice « test du patron de bar » (10 secondes). Puis Prompt 35 du Kit (pitch 30 s) dans Claude / ChatGPT : 3 versions, vous choisissez.

⚡
Bloc 3 — Construction live (1 h 30)

Sans site : page d'accueil depuis une démo. Avec site : amélioration + formulaire + notification test sur mobile. A/B test rapide de libellés de CTA.

✓
Bloc 4 — Autonomie (30 min)

Vous modifiez seul (texte bouton, téléphone footer, publication) sous nos yeux — objectif : zéro blocage technique.

Pour qui

  • Dirigeant·e de TPE qui a un site « qui traîne » ou pas de site du tout
  • Artisan, libéral ou commerçant qui veut un message clair avant de payer une grosse refonte
  • Équipe réduite : vous devez pouvoir ajuster texte & CTA sans développeur

FAQ

Faut-il déjà avoir un nom de domaine ?

Non. Si vous n'avez pas encore d'URL, on travaille sur une base démo que vous pourrez migrer ensuite.

C'est en présentiel uniquement ?

Oui, cette offre est calibrée pour du live (visio possible sur demande lors du diagnostic). Le diagnostic en ligne sert à qualifier le besoin.

Que se passe-t-il si je ne finis pas la page en 1 h 30 ?

On priorise un livrable minimal viable : message + CTA + structure. Le replay vous permet de terminer avec le doc récap.
