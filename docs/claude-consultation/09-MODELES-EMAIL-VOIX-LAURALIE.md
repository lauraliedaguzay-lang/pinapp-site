# 09 — Modèles d’e-mails (voix Lauralie) — prêts à copier-coller

Objectif : te faire gagner du temps sans t’enfermer dans un ton “template”.

## Règles de style (voix Pinapp)

- **Je** / **vous** (pas “nous” corporate).
- Phrases **courtes**. Un seul sujet par paragraphe.
- **Concret** : une action, une date, un choix.
- **Pas de promesse magique**, pas de jargon (API, CRM, pipelines…).
- **Jamais d’envoi automatique** : ces textes sont faits pour des **brouillons** que tu valides.

Signature recommandée (simple) :

```
Lauralie
Pinapp Studio
```

---

## 1) Réponse à une demande (diagnostic) — “bien reçu + prochaine étape”

**Sujet :** `Bien reçu — votre demande Pinapp`

```
Bonjour {{prenom}},

Bien reçu.

Pour être sûre de viser juste, j’ai besoin de 3 infos :
1) {{question_1}}
2) {{question_2}}
3) {{question_3}}

Dès que j’ai ça, je vous réponds avec une proposition claire (périmètre + ordre + budget).

Lauralie
Pinapp Studio
```

Variantes de questions (à choisir selon le cas) :
- “Quel est votre objectif le plus important (1 seule phrase) ?”
- “Quel est votre service / offre principale ?”
- “Quelle est votre contrainte n°1 : délai, budget, énergie, autre ?”

---

## 2) Diagnostic — “proposition de créneau (Google Meet)”

**Sujet :** `Proposition de créneau — Google Meet`

```
Bonjour {{prenom}},

Je vous propose un échange court sur Google Meet pour cadrer.

Voici 2 options :
- {{creneau_1}}
- {{creneau_2}}

Quel créneau vous va ?

Lauralie
Pinapp Studio
```

---

## 3) Après diagnostic — “synthèse + 2 choix”

**Sujet :** `Synthèse + 2 options pour avancer`

```
Bonjour {{prenom}},

Voici la synthèse (courte) :
- Situation : {{situation}}
- Objectif : {{objectif}}
- Point de friction : {{friction}}

Option A (simple) : {{option_a}}
Option B (plus complet) : {{option_b}}

Vous préférez A ou B ?

Lauralie
Pinapp Studio
```

---

## 4) Relance douce — “aucune pression”

**Sujet :** `Je vous laisse choisir`

```
Bonjour {{prenom}},

Je reviens vers vous : est-ce que c’est toujours d’actualité de votre côté ?

Si oui, dites-moi simplement :
- “on avance” (et je vous propose la prochaine étape)
- ou “pas maintenant” (et je n’insiste pas)

Lauralie
Pinapp Studio
```

---

**Sujet :** `Reçu — on démarre`

```

Bien reçu pour {{paiement}}.

Prochaine étape : {{prochaine_etape}}.
Je vous écris dès que c’est prêt à valider.

Lauralie
Pinapp Studio
```

## 6) Demande d’éléments (site) — “checklist courte”

**Sujet :** `Pour avancer, j’ai besoin de 5 éléments`

```
Bonjour {{prenom}},

Pour avancer proprement, j’ai besoin de :
1) {{element_1}}
2) {{element_2}}
3) {{element_3}}
4) {{element_4}}
5) {{element_5}}

Envoyez-moi tout en une fois si possible.
Dès que c’est bon, je vous donne l’étape suivante.

Lauralie
Pinapp Studio
```
