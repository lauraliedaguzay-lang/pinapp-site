## Objectif ops

Le site **pinapp.fr** (et miroirs) doit rester **en ligne** avec **peu d’intervention quotidienne** : hébergement managé, **déploiement par push** (GitHub Actions), **health checks** + alertes en cas de panne.

## Bonnes pratiques retenues pour Pinapp

- Hébergement **statique** (Pages / CDN), pas de serveur à maintenir à la main pour la vitrine.
- Formulaires / automatisations : services **managés** (webhooks, Apps Script, tiers type Tally/Formspree) plutôt qu’API maison non surveillée.
- Après déploiement : vérifier HTTP 200, assets, liens principaux.

## Monitoring

- Liste d’URLs à sonder (prod Pinapp + Pages) ; alerte e-mail si KO.
- En panne : vérifier GitHub Actions, derniers commits, revert si régression.
