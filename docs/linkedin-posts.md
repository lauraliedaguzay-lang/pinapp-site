## Notes générales

- **Tone** : authentique, direct, premier degré. Pas de buzzwords. Pas de « disruptif », « innovant », « game changer ».
- **Format** : tous les posts font 500-900 caractères → sweet spot LinkedIn pour l'engagement.
- **Hashtags** : optionnel. Si tu en mets, max 3, en fin de post : `#TPE #Bordeaux #Automatisation` ou similaires selon le post.
- **Image / vidéo** : un post LinkedIn avec un visuel a 2× plus d'engagement. Suggestions :
  - Post 2 : screenshot du score Lighthouse 97
  - Post 3 : photo de Michaël (ou capture d'un film)
  - Post 5 : screenshot de la démo NAÏLA
  - Post 8 : un visuel « 16 → 4 » fait avec Canva
- **CTA en commentaire** : LinkedIn pénalise les liens dans le post. Mets toujours le lien `pinapp.fr` en **premier commentaire**.
- **Réponses** : engagement réel. Tu réponds aux 5-10 premiers commentaires dans les 1-2 h → le post est boosté par l'algo.
