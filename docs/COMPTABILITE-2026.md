# Comptabilité 2026 — gabarit Pinapp

Document interne. Ne remplace pas un expert-comptable ni les obligations légales.

## Objectif

Centraliser le suivi **CA**, **dépenses**, **URSSAF / TVA** (art. 293 B si applicable) et les **seuils** micro-entreprise (référence légale à jour avec votre conseil).

## Notion — 3 bases suggérées

1. **Factures émises** : date, client, N° facture (ex. PP-2026-xxx), montant HT, TVA, statut (envoyée / payée).
2. **Dépenses** : date, fournisseur, catégorie, montant, pièce jointe (Drive).
3. **URSSAF trimestriel** : période, montant déclaré, date paiement, lien déclaration.

Vue **tableau de bord** : CA cumulé mois / trimestre / année ; alerte si approche du plafond BNC (valeur légale du moment).

## Règles dépôt

- Pas de montants réels ni de secrets dans ce fichier versionné.
- Les exports CSV / PDF restent dans Drive ou Notion privé.
