## PROMPT 1 · Description produit/service qui vend

🎯 Objectif : Rédiger une description de votre service qui donne envie d'acheter  
👤 Pour qui : Tous secteurs  
⏱ Temps gagné : 30 min

**PROMPT :**

```
Tu es un copywriter senior spécialisé dans les TPE françaises. Rédige une description commerciale pour ce service :

Métier : [votre métier]
Service : [nom du service]
Pour qui : [votre client type]
Prix : [votre prix]
Ce qui rend ce service unique : [votre force]

La description doit :
- Commencer par le PROBLÈME du client (pas par le service)
- Montrer le RÉSULTAT concret (pas les caractéristiques)
- Inclure un appel à l'action naturel
- Faire entre 80 et 150 mots
- Ton : professionnel mais chaleureux, pas corporate
```

💡 ASTUCE : Remplacez les [crochets] par vos infos. Plus vous êtes précis, meilleur sera le résultat.

```

Prestation demandée : [description]

Prix total : [montant HT]

7. Note finale chaleureuse (1 phrase)

## PROMPT 9 · Post LinkedIn storytelling

🎯 Objectif : Écrire un post LinkedIn qui génère de l'engagement  
👤 Pour qui : Tous secteurs  
⏱ Temps gagné : 30 min

**PROMPT :**

```
Rédige un post LinkedIn basé sur cette situation vécue dans mon travail :

Mon métier : [votre métier]
La situation : [racontez brièvement ce qui s'est passé]
La leçon : [ce que vous en avez tiré]
Mon objectif avec ce post : [notoriété / clients / recrutement / partage]

Structure AIDA :
1. ACCROCHE : 1ère ligne qui arrête le scroll (max 10 mots, percutante)
2. HISTOIRE : racontez la situation en 5-6 lignes courtes (1 idée par ligne, retours à la ligne fréquents)
3. LEÇON : ce que ça vous a appris (2-3 lignes)
4. APPEL : question ouverte pour les commentaires

Règles :
- Lignes courtes (max 10 mots par ligne)
- PAS de hashtags dans le texte (les mettre à la fin, séparés)
- PAS d'emojis au début de chaque ligne
- Ton : authentique, pas motivational speaker
- 5-8 hashtags pertinents à la fin
- 150-200 mots max
```

## PROMPT 25 · Script d'appel prospection

🎯 Objectif : Appeler un prospect sans lire un script robot  
👤 Pour qui : Tous  
⏱ Temps gagné : 30 min

**PROMPT :**

```
Crée un script d'appel de prospection naturel.

Mon métier : [votre métier]
J'appelle : [type de prospect — ex: restaurant qui n'a pas de site]
Comment j'ai trouvé cette personne : [Google / recommandation / réseaux]
Mon objectif : [prendre rdv / proposer un diagnostic / envoyer un devis]

- Commencer par une QUESTION (pas par une présentation)

- Conclure par une action claire (rdv, envoi d'info)

Format : dialogue naturel avec [ce que je dis] et (ce que le prospect pourrait répondre).
JAMAIS : "Je me permets de vous appeler" ou "Auriez-vous un moment à m'accorder".
