## 10. RÈGLES ÉDITORIALES

### Voix Pinapp (résumé)
- **"Nous"** pour Pinapp (jamais "je" sauf dans un quote signé Lauralie ou Michaël)
- **"Vous"** pour le client (pas de tutoiement)
- Phrases courtes préférées, rythme ternaire fréquent
- Tirets courts (–) ou longs (—) pour interruptions
- Italiques pour citations, noms techniques (n8n, M&P)
- **Chiffres concrets**, pas hyperboles ("environ 3h / semaine" pas "des milliers")
- **Comparaisons tangibles** ("moins qu'un mois de Google Ads" pas "très économique")

### Mots SIGNATURE (à favoriser)
Sobriété · Traçabilité · Lisibilité · Sur-mesure · Rigueur · Pragmatisme · Sans la boîte noire magique · Rien sans accord explicite · Du bon sens produit · Repartir avec · Ici et maintenant

### Mots BANNIS
- "opportunités" (corporate fade)
- "appel" (commerce agressif)
- "systèmes digitaux" (abstraction qui parle à personne)
- "transformation digitale" · "synergies" · "disruption" · "10x" · "révolutionnaire"
- "Nous sommes une petite équipe mais…" (fausse humilité)

## 12. RÈGLE AVATAR (principe visuel suprême)

> **Si le visiteur remarque un effet → trop fort.**
> **Si le site semble vivant sans qu'on sache pourquoi → réussi.**

**Application copy** : éviter les phrases qui se lisent comme des slogans. Préférer les phrases qui se lisent comme des constats.

**Test ultime** : si la phrase pourrait apparaître dans un manifeste d'agence générique → la réécrire.
Si elle ne peut exister que chez Pinapp → elle reste.

### Œuf #2 — Morse STAY (s4 Mémoire & Présence)

**Placement** : `position: fixed; bottom: 2rem; left: 2rem;` · visible uniquement quand `data-active-section="s4"` sur le `<html>`.

**Motif morse pour "STAY"** :
```
S = ...       (3 dots)
T = -          (1 dash)
A = .-         (dot + dash)
Y = -.--       (dash dot dash dash)
```

**HTML** :
```html
<div class="morse-stay" aria-hidden="true" data-word="STAY">
  <!-- S -->
  <span class="dot"></span><span class="dot"></span><span class="dot"></span>
  <span class="letter-gap"></span>
  <!-- T -->
  <span class="dash"></span>
  <span class="letter-gap"></span>
  <!-- A -->
  <span class="dot"></span><span class="dash"></span>
  <span class="letter-gap"></span>
  <!-- Y -->
  <span class="dash"></span><span class="dot"></span><span class="dash"></span><span class="dash"></span>
</div>
```

**CSS** :
```css
.morse-stay {
  position: fixed;
  bottom: 2rem;
  left: 2rem;
  display: flex;
  align-items: center;
  gap: 6px;
  opacity: 0;
  transition: opacity 800ms ease;
  z-index: 10;
  pointer-events: none;
}
html[data-active-section="s4"] .morse-stay {
  opacity: 0.5;
}
.morse-stay .dot,
.morse-stay .dash {
  background: rgba(62, 245, 224, 0.7);
  border-radius: 999px;
  animation: morse-blink 6s infinite ease-in-out;
}
.morse-stay .dot { width: 6px; height: 6px; }
.morse-stay .dash { width: 16px; height: 6px; }
.morse-stay .letter-gap { width: 8px; height: 6px; }
@keyframes morse-blink {
  0%, 100% { opacity: 0.3; }
  50% { opacity: 1; }
}
```

**Zéro texte visible. Zéro attribution.** Les devs/initiés qui regardent le DOM voient le `data-word="STAY"`.
