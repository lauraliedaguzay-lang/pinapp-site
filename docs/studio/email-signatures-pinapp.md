## Installer dans Gmail

1. Gmail → ⚙️ Paramètres → Voir tous les paramètres  
2. Onglet « Général » → Signature  
3. Cliquer « + Créer » → nommer par ex. « Pinapp »  
4. Coller le HTML (si Gmail refuse le HTML brut, coller le rendu depuis un navigateur)  
5. Enregistrer  

## Envoyer depuis `contact@pinapp.fr`

- Gmail → Paramètres → Comptes → « Envoyer des e-mails en tant que » → Ajouter `contact@pinapp.fr`  
- SMTP : `smtp.hostinger.com` — port **465** — SSL  
- Identifiant : `contact@pinapp.fr` + mot de passe boîte Hostinger
