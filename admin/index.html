Pinapp — console studio

Gestion studio (Lauralie & Michaël), catalogue, pages publiques et JSON. En production sur Netlify, le mot de passe est vérifié par la fonction /.netlify/functions/admin-session (variable PINAPP_ADMIN_PASSWORD). Sans cette variable, un mot de passe de secours dans assets/js/admin-dashboard.js sert pour le dev local uniquement — complétez par Basic Auth ou règles Netlify si besoin.

Studio — pilotage, catalogue & aperçu

Sécurité : avec PINAPP_ADMIN_PASSWORD sur Netlify, la connexion passe par le back-end ; le jeton de session est stocké en sessionStorage. Le mot de passe dans le JS ne doit servir qu’en secours (dev / sans env). Pour un accès renforcé, gardez une protection hébergeur (Basic Auth, etc.).

Contenu aligné sur les pages formation-gratuite et offres/formation. Modifier le fichier assets/data/pinapp-catalog.json pour mettre à jour l’API et les listes.
